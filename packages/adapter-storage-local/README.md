# `@nodera/adapter-storage-local` — reserved placeholder

Intentionally empty, `private` and not published: no `src`, no build, no tests,
no exports. Do not depend on it.

Nodera imposes no storage backend: [`@nodera/document`](../document/README.md)
defines the portable format and the serializers the text encodings, while the
host decides where documents are stored. See
`odd/tasks/fase8-production-readiness.md` (D3/D11).
