# Changelog

This repository does not keep a hand-written changelog. Per-package changelogs
are generated by [`@changesets/cli`](https://github.com/changesets/changesets)
from the changesets committed with each change.

- Changelog entries are written by `pnpm version` (`changeset version`), which
  reads `.changeset/*.md` and writes each affected package's `CHANGELOG.md`.
- Release notes for a published package therefore live next to that package
  (`packages/<name>/CHANGELOG.md`), not in this file.
- There is no release history yet: the publishable packages are at `1.0.0`
  (`@nodera/sdk` exports `SDK_VERSION = "1.0.0"`), and the workspace root stays
  at `0.0.0` and is `private`.

To add an entry for your change:

```bash
pnpm changeset
```

See [`CONTRIBUTING.md`](CONTRIBUTING.md) for the full contributor flow.
